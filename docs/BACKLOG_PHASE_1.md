# Backlog Phase 1

## Objetivo da fase

Sair do planejamento abstrato e entrar na preparacao de implementacao sem escrever ainda o jogo.

## Prioridade Must

- definir engine final e registrar a decisao
- capturar referencia visual e mecanica do original
- recortar a missao do vertical slice
- definir politica de assets placeholders
- mapear sistemas essenciais do core loop

## Prioridade Should

- comparar Godot vs C++ em um mini-spike documental
- listar todos os elementos do HUD e sua funcao
- decompor armas, pickups e tipos de inimigo
- definir formato de documento de missao

## Prioridade Could

- preparar quadro de telemetria para playtest futuro
- estudar pipeline de importacao de dados antigos para referencia interna
- desenhar um mapa de fluxo do jogo original

## Sequencia sugerida

1. documentar referencia do original
2. congelar o escopo do vertical slice
3. aprovar stack tecnica
4. definir arte placeholder
5. abrir a fase de implementacao

## Definicao de pronto da fase

- existe uma lista fechada do que entra no vertical slice
- existe uma stack final escolhida
- existe um conjunto de referencias suficiente para evitar adivinhacao
- existe clareza sobre o que e inspirado e o que e original
